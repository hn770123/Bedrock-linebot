# バレエ教室向け自動翻訳LINE Bot 企画書

## 1. プロジェクト概要

### 1.1 目的
子供バレエ教室において、ポーランド人講師と日本人保護者の円滑なコミュニケーションを支援する自動翻訳LINE Botを開発する。

### 1.2 背景
- バレエ教室の講師はポーランド人で、主に英語とポーランド語を使用
- 生徒の保護者は日本人で、主に日本語を使用
- 言語の壁によるコミュニケーションの課題が存在
- レッスンスケジュール、イベント情報、子供の進捗状況などの共有が必要

### 1.3 対象ユーザー
- **ポーランド人バレエ講師**: 英語・ポーランド語話者
- **日本人保護者**: 日本語話者

## 2. 機能要件

### 2.1 翻訳機能

#### 2.1.1 言語検出と翻訳方向
- **入力が英語またはポーランド語の場合**
  - → 日本語に翻訳

- **入力が日本語の場合**
  - → 英語とポーランド語の両方に翻訳

#### 2.1.2 翻訳品質向上のための工夫
以下のコンテキスト情報を活用し、高精度な翻訳を実現する:

1. **専門用語辞書の実装**
   - バレエ用語の翻訳辞書
   - 例: プリエ(plié)、アラベスク(arabesque)、ピルエット(pirouette)など

2. **コンテキスト対応**
   - 子供の年齢層を考慮した表現（幼児〜小学生）
   - バレエ教室特有の文脈（発表会、レッスン、衣装、練習など）
   - 保護者向けの丁寧な表現

3. **プロンプトエンジニアリング**
   - Amazon Bedrock（Claude）に対して、以下のコンテキストを含めた翻訳指示:
     - 「子供バレエ教室の講師と保護者間のコミュニケーション」
     - 「礼儀正しく、温かみのある表現を使用」
     - 「バレエ用語は専門用語として正確に翻訳」

### 2.2 メッセージ処理フロー

```
ユーザーメッセージ受信
    ↓
言語検出
    ↓
翻訳方向の決定
    ↓
コンテキスト付きで翻訳実行
    ↓
翻訳結果をLINEに返信
```

### 2.3 表示形式
翻訳結果は以下の形式で返信:

**日本語→英語・ポーランド語の場合:**
```
🇬🇧 英語:
[英語翻訳]

🇵🇱 ポーランド語:
[ポーランド語翻訳]
```

**英語・ポーランド語→日本語の場合:**
```
🇯🇵 日本語:
[日本語翻訳]
```

## 3. 技術スタック

### 3.1 インフラストラクチャ
- **AWS Lambda**: サーバーレス実行環境
- **Amazon API Gateway**: LINE Webhook エンドポイント
- **Amazon Bedrock**: AI翻訳エンジン（Claude 3.5 Sonnet推奨）
- **AWS Systems Manager Parameter Store**: 機密情報管理（LINE Channel Secret等）

### 3.2 開発言語
- **Python 3.12**: Lambda関数の実装言語
- **boto3**: AWS SDK

### 3.3 外部サービス
- **LINE Messaging API**: LINE Botインターフェース

## 4. システム構成

### 4.1 アーキテクチャ図

```
LINE App (ユーザー)
    ↓
LINE Messaging API
    ↓
Amazon API Gateway
    ↓
AWS Lambda (翻訳処理)
    ↓
Amazon Bedrock (Claude 3.5 Sonnet)
    ↓
AWS Lambda (翻訳処理)
    ↓
LINE Messaging API
    ↓
LINE App (ユーザー)
```

### 4.2 データフロー

1. **受信フロー**
   - ユーザーがLINEでメッセージを送信
   - LINE Messaging APIがWebhookを送信
   - API Gatewayが受信してLambdaをトリガー

2. **処理フロー**
   - Lambda関数がメッセージを解析
   - 言語を検出（日本語 or 英語/ポーランド語）
   - Bedrockを使用して翻訳を実行
   - バレエ用語辞書による補正

3. **送信フロー**
   - 翻訳結果をフォーマット
   - LINE Messaging APIで返信

## 6. セキュリティ・プライバシー

### 6.1 認証とアクセス制御
- LINE Messaging APIの署名検証
- AWS IAMロールによる最小権限の原則
- API Gatewayでのリクエスト検証

### 6.2 データ保護
- メッセージログは保存しない（プライバシー保護）
- 機密情報はParameter Storeで暗号化保存
- HTTPS通信の徹底

## 7. コスト見積もり

### 7.1 月間想定コスト（100メッセージ/日として）

- **AWS Lambda**: 〜$1
  - 3,000リクエスト/月
  - 実行時間: 3秒/リクエスト

- **Amazon Bedrock**: 〜$15-30
  - Claude 3.5 Sonnet使用
  - 入力: 約300トークン/リクエスト
  - 出力: 約150トークン/リクエスト

- **API Gateway**: 〜$0.01
  - 3,000リクエスト/月

**合計**: 月額約$16-31（約2,500〜4,500円）

### 7.2 コスト最適化案
- メッセージのキャッシング（同じ質問への再利用）
- より軽量なモデル（Claude Haiku）の検討
- Lambda関数の実行時間最適化

## 12. まとめ

本プロジェクトは、AWS Lambda と Amazon Bedrock を活用し、バレエ教室における言語の壁を解消する自動翻訳LINE Botを実現します。単なる機械翻訳ではなく、バレエ教室特有のコンテキストを理解した高精度な翻訳により、講師と保護者の円滑なコミュニケーションを支援します。
